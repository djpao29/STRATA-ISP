# wispx-icons

49 icons in the **wispx-line-soft** style, drawn on a 24 px grid with a 20 px live area.
Generated by the `generate-icons` skill from `icons.json`. Do not edit the generated files by hand:
change the source and run the build again.

## Use

```tsx
import { DashboardIcon } from "wispx-icons"
// or, for the smallest bundle: import DashboardIcon from "wispx-icons/icons/dashboard"

<DashboardIcon />                       // decorative: aria-hidden
<DashboardIcon size={16} title="Dashboard" /> // informative: role="img" + <title>
```

- `size` sets width and height (default 24).
- Without `title` or `aria-label` the icon is decorative and gets `aria-hidden`.
  With either one it becomes `role="img"` with an accessible name. Use that when the icon is the only
  thing that carries the meaning (an icon-only button still needs its own `aria-label` on the button).
- Each icon is its own module, so bundlers keep only the ones you import.

## Colors and states

Every shape is painted with a CSS variable per tone (`--wx-line`, `--wx-fill`), falling back to `currentColor`, so the icons work with no setup. Import `icons.css` once to get the exact palette, states and dark mode:

```css
@import "wispx-icons/icons.css";
```

States follow the markup: `:hover` on links and buttons, `aria-current="page"`, `aria-selected`, `aria-pressed` and `data-icon-state="active"` for active, `:disabled`, `aria-disabled` and `data-icon-state="disabled"` for disabled. Dark mode follows `[data-theme="dark"], .dark`. To recolor one place, set the variables there:

```css
.on-brand { --wx-line: currentColor; --wx-fill: currentColor; }
```

## Files

| Path | What it is |
|------|------------|
| `src/` | One component per icon plus an index (absent for plain SVG). |
| `svg/` | Standalone SVGs with the default light palette in hex: for `<img>`, e-mail, Figma. |
| `sprite.svg` | All icons as `<symbol>`, painted with the CSS variables. |
| `icons.css` | The tone variables per state and theme. |
| `manifest.json` | Names, labels, groups and tags, for search or docs. |
| `catalog.html` | Review page: every icon in every state and size, light and dark. |
